《風聲》108 張版本的網頁實作：3D 牌桌、雲端遊戲伺服器、3–9 人連線或單機對戰 AI。

## 規則範圍

身份牌 9 張、遊戲牌 81 張、角色牌 18 張。每張遊戲牌同時是功能牌與情報，右上角印章決定傳遞方式（密電 32、直達 32、文本 17），顏色為紅 25、藍 25、假 31。

| --- | --- | --- | --- |

| 識破 | 5／5／4 | 直達 | 有人使用卡牌時 |
| 鎖定 | 3／3／6 | 直達 | 自己回合的出牌或傳遞時 |
| 截獲 | 1／1／6 | 密電 | 他人回合的傳遞時 |
| 退回 | 3／3／2 | 文本 | 情報傳到你時 |
| 調虎離山 | 2／2／2 | 文本 | 傳遞時 |
| 破譯 | 2／2／2 | 密電 | 情報傳到你時 |

| 真偽莫辨 | 1／1／1 | 文本 | 自己的出牌階段 |

| 人數 | 陣營配置（潛伏／軍情／特工） |

結算：每次傳遞的每一跳分「傳遞時」「傳到時」「決定是否接收」三段。卡牌使用後進入堆疊，從使用者右手邊依座位詢問是否回應，所有人放棄後後用的先生效（後發先至）。

規則解讀：試探卡文字依原規則結構補上；棄牌一律暗棄；只看角色性別，蓋伏時無性別。

## 系統架構

全部用 TypeScript。前端 React + Three.js（@react-three/fiber），後端是 Cloudflare Worker 與 Durable Objects，同一個網址提供網頁、開房 API 與 WebSocket。

| 模組 | 檔案 | 職責 |
| --- | --- | --- |
| 規則引擎 | `src/engine/` | 純函式：狀態 + 動作 → 新狀態；技能佇列、堆疊結算、勝負；`viewFor` 只產生某位玩家看得到的資訊 |
| AI | `src/ai/ai.ts` | 只讀自己的視角，依收情報的顏色猜敵友 |
| 執行器 | `src/shared/runner.ts` | AI 延遲、真人倒數、逾時代打（伺服器與單機共用） |
| 房間伺服器 | `src/server/worker.ts` | 每個邀請碼一個 Durable Object：成員、設定、聊天、遊戲狀態，存在它內建的 SQLite |
| 連線 | `src/client/net/session.ts` | WebSocket、自動重連、心跳 |
| 語音 | `src/client/net/voice.ts` | WebRTC mesh，信令經伺服器轉送；可選 Cloudflare TURN 中繼 |
| 3D 牌桌 | `src/client/three/` | 人物、桌面情報、卷宗動畫；牌面以 canvas 畫成貼圖 |
| 介面 | `src/client/ui/` | 大廳、房間、操作區、說明頁 |

遊戲狀態只在伺服器上，瀏覽器只收到自己的視角，別人的手牌、身份、蓋伏的角色都不會傳到你的電腦。

## 連線與房間行為

| 情況 | 行為 |
| --- | --- |
| 建立房間 | 伺服器產生 5 碼邀請碼（不含易混淆的 0、O、1、I），可複製邀請連結 |
| 加入 | 開連結或輸入邀請碼；不存在的代碼會被拒絕；最多 9 人；開始後拒絕新玩家 |
| 房主 | 建房的人；房主在開局前離開時，自動交給下一位 |
| 玩家斷線 | 15 秒內回來無影響；超過由 AI 代打 |
| 重連 | 同一瀏覽器重新加入認回原座位；客戶端自動重連 2 分鐘 |
| 全部離線 | 遊戲暫停並存檔，有人回來再繼續；閒置 7 天刪除房間 |

決定時限（連線模式）：挑角色 60 秒、出牌 90 秒、回應 20 秒、接收 30 秒、技能與棄牌 30 秒；逾時時回應自動略過，其他由 AI 代為決定。

## 介面

1940 年代諜報主題：昏黃吊燈下的胡桃木圓桌，特工穿風衣、戴紳士帽圍坐；自己的座位在鏡頭前方（不畫自己的人物）。

- 每位玩家頭上有名牌：名字、手牌數、角色、狀態標籤。
- 收下的情報面朝上排在各自面前的桌上。
- 傳遞中的情報是一份蓋了「密電／直達／文本」印章的牛皮紙卷宗，從天而降壓上印章，再移到目前拿著它的人面前，被收下時縮小消失。
- 正在等誰行動，他面前桌緣亮起金色光圈，名牌標「行動中」；輪到自己時操作區變色並顯示倒數。
- 可拖曳旋轉、縮放視角；系統設定「減少動態效果」時關閉動畫。

## 部署與測試

推送到 main 後，GitHub Actions 跑測試、建置，再用 Wrangler 部署到 Cloudflare。需要在 GitHub repo 的 Secrets 設定 `CLOUDFLARE_API_TOKEN` 與 `CLOUDFLARE_ACCOUNT_ID`。

| 測試 | 內容 |
| --- | --- |
| 單元測試 | 牌組數量、流程、視角保密、技能（禮服蒙面人、刀鋒、貝雷帽、老鬼） |
| AI 自動對戰 | 3–9 人各種配置，81 張牌守恆、18 個技能都觸發 |
| 伺服器實測 | 本機 wrangler：開房、拒絕錯誤代碼、聊天、房主權限、打完整局、斷線重連、回到房間 |

免費方案額度：Durable Objects 每日 100,000 次請求；WebSocket 收到的訊息以 20:1 計算，朋友局綽綽有餘。

# 風聲 遊玩說明

打開網站，輸入名字：一人按「建立房間」、其他人用邀請碼加入就能開始，人數不夠會由電腦補位。

## 開始遊戲

**建立房間（一個人）**

1. 在首頁輸入名字，按「建立房間」。
2. 畫面上會出現 5 碼邀請碼，按「複製邀請連結」傳給朋友。
3. 等大家進房後，選遊戲人數與陣營配置，按「開始遊戲」。

**朋友加入**

1. 打開邀請連結，輸入名字，按「加入房間」；也可以在首頁輸入邀請碼後按「加入」。
2. 中途斷線或重新整理，用同一個瀏覽器重新打開連結就會回到原本的座位與手牌。斷線超過 15 秒，這段時間由電腦暫時代打。

遊戲在雲端伺服器上進行，任何網路（家裡、宿舍、手機 4G/5G）都能連；建房的人關掉網頁也不會影響其他人。

**一個人練習**：首頁的「單機對戰 AI」選人數就能開始，沒有時間限制。

## 遊戲目標

每個人的身份是秘密，畫面右側只有你自己看得到。靠大家收情報的樣子推理誰是隊友。

| 身份 | 怎麼贏 |
| --- | --- |
| 潛伏戰線（紅） | 任何一位成員面前集滿三張紅色情報，全隊一起贏 |
| 軍情局（藍） | 任何一位成員面前集滿三張藍色情報，全隊一起贏 |
| 特工 | 完成自己角色卡上的「機密任務」，自己一個人贏（開了特工同盟時，所有特工一起贏） |

- 面前收到三張假情報（黑色）就死亡。
- 輪到你出牌卻沒有手牌可以當情報傳出，就輸掉遊戲。

## 一回合的流程

1. **抽牌**：抽 2 張（大美女抽 3 放回 1）。
2. **出牌**：可以先用功能牌（試探、燒毀、鎖定、真偽莫辨），次數不限。
3. **傳情報**：必須挑一張手牌當作情報傳出，每回合正好一張。
4. 情報被某人收下後，換右手邊的下一位玩家。

每張牌都有兩種用法：當功能牌使用，或當情報傳出。當情報時只看它的顏色（紅、藍、假）和右上角印章（傳遞方式）。

## 情報怎麼傳

| 印章 | 怎麼傳 | 大家看得到內容嗎 |
| --- | --- | --- |
| 密電 | 蓋著往右手邊一位一位傳 | 看不到（破譯可偷看） |
| 文本 | 翻開往右手邊一位一位傳 | 所有人看得到 |
| 直達 | 蓋著直接交給你指定的人，他不收就退回給你 | 看不到 |

每一跳情報都經過三個時機：

1. **傳遞時**：可用鎖定（傳出者）、調虎離山、截獲（傳出者以外）。
2. **傳到某人面前**：他可用破譯、退回。
3. **決定收不收**：這一刻誰都不能插入用牌。被鎖定、或情報繞一圈回到傳出者時，必須收。

不收的話：密電／文本傳給下一位，直達退回傳出者。

## 功能牌速查

| 牌 | 什麼時候用 | 效果 | 小提醒 |
| --- | --- | --- | --- |
| 試探 | 自己的出牌階段 | 交給一人，他依真實身份抽二張、棄一張或說「我是好人／臥底」 | 只有你和他看得到猜的是哪個陣營 |
| 鎖定 | 自己回合（出牌或傳遞時） | 情報傳到他時他必須收 | 先鎖定敵人，再把假情報直達給他 |
| 截獲 | 別人回合的傳遞時 | 直接拿走傳遞中的情報 | 看得到內容（文本）時最好用 |
| 退回 | 情報傳到你面前時 | 情報改往反方向傳 | 被鎖定時沒用 |
| 調虎離山 | 傳遞時 | 指定一人這次跳過 | 可以對自己用 |
| 破譯 | 情報傳到你面前時 | 先偷看內容再決定收不收 | 文本本來就看得到 |
| 燒毀 | 任何可以出牌的時候 | 燒掉任一人一張假情報 | 救自己或隊友免於第三張假情報 |
| 識破 | 別人用牌時 | 那張牌無效 | 識破也能被識破，最後出的先生效 |
| 真偽莫辨 | 自己的出牌階段 | 翻出存活人數張牌，從你開始每人選一張當情報 | 選的時候看不到內容 |

## 角色與技能

- **潛伏角色**（老鬼、譯電員、老槍、閃靈、黑玫瑰、峨嵋風、老金）開局蓋著；蓋著時只能用「翻開此角色」的技能，翻開後其他技能才生效。
- **公開角色**開局就翻開；被老槍蓋伏後技能失效。
- **主動技能**：能發動時，操作區出現金色按鈕。
- **觸發技能**：時機到了系統會問「要發動嗎？」。
- **需要選擇時**：點選項、玩家名字、手牌或情報，再按「確定」。
- **當作其他牌**：刀鋒的試探、職業殺手的識破、貝雷帽的黑色牌可以「當作鎖定」；貝雷帽傳密電或文本時可以選方向。
- 機密任務只在身份是特工時才是勝利條件。性別只看角色卡，角色蓋著時沒有性別。

## 畫面怎麼看

| 畫面上的 | 意思 |
| --- | --- |
| 頂部「你的回合」金色標籤 | 現在是你的回合 |
| 桌緣亮起金色光圈、名牌標「行動中」 | 正在等這位玩家決定 |
| 操作區變色、出現「輪到你了」 | 你要出牌或回答問題；「你可以回應」代表可以用牌但不是必須 |
| 蓋了印章的牛皮紙卷宗 | 傳遞中的情報，在桌上移到目前拿著它的人面前 |
| 每人面前桌上的牌 | 他收下的情報（紅、藍、黑＝假） |
| 「鎖定」「調虎離山」標籤 | 這回合被鎖定（必須收）或被調開（跳過） |
| 紀錄中「僅你可見」 | 只有你看得到的資訊 |

用滑鼠拖曳或手指滑動可以旋轉視角，滾輪或雙指可以縮放。

## 小技巧

- 回應時機很多，按「本回合都略過」可自動略過與你無關的時機。
- 連線時每個決定有時間限制（回應 20 秒、出牌 90 秒），時間到會自動略過或由電腦代為決定。
- 切到別的分頁時，分頁標題出現「● 輪到你了」就該回來了。
- 按「加入語音」開麥克風就能直接通話，可以靜音。

## 常見問題

**連不上房間？** 確認邀請碼正確；房間閒置 7 天會被清除。

**語音沒聲音？** 瀏覽器要允許麥克風（網址列左邊的圖示）；雙方都要按「加入語音」。

**對局紀錄存在哪？** 存在你自己的瀏覽器，首頁「最近對局」可以看到。
